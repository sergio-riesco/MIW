1. CONTENIDO DEL SITIO
------------------------------------------------------------------

El sitio está en español (raíz) y en inglés (bajo /en). Cada página
tiene su equivalente en el otro idioma:

  Español                Inglés             Contenido
  /                      /en                Sobre mí: foto, resumen de
                                            estudios y experiencia, y
                                            contacto.
  /formacion             /en/education      Grado, máster (con fechas) y
                                            prácticas en Mecalux.
  /musica                /en/music          Grupos favoritos agrupados
                                            por género.
  /musica/<genero>       /en/music/<genero> Cada género, con un fragmento
                                            de audio de cada álbum.
  /videojuegos           /en/videogames     Videojuegos favoritos y el que
                                            estoy jugando, con tráileres.
  /series                /en/series         Series favoritas y la que
                                            estoy viendo, con tráileres.
  /hobbies               /en/hobbies        Aficiones: videojuegos, skate
                                            y pizzas.
  /contacto              /en/contact        Correo, GitHub y personas que
                                            me avalan.
  /buscar?q=...          /en/search?q=...   Buscador del sitio.
  /mapa                  /en/sitemap        Mapa del sitio.
  /ayuda                 /en/help           Ayuda: cómo moverse por el
                                            sitio y cómo enviar
                                            sugerencias.
  /sitemap.xml, /robots.txt                 Para los buscadores.

Todas las páginas comparten cabecera (buscador, enlace al otro idioma
y botón de modo claro/oscuro), menú principal con la sección actual
marcada, migas de pan y pie con enlaces al mapa, la ayuda y el
contacto, un enlace para enviar sugerencias y la fecha de la última
actualización.

En el móvil la cabecera solo muestra el nombre, el botón de tema y un
botón «Menú» que despliega el buscador, los enlaces y el cambio de
idioma. Sin JavaScript el menú se muestra siempre abierto.


2. TECNOLOGÍAS Y JUSTIFICACIÓN
------------------------------------------------------------------

  - Next.js 16 (App Router) con React 19.
      Permite escribir la cabecera, la navegación y las tarjetas una
      sola vez como componentes y reutilizarlas en todas las páginas.
      Las páginas se generan en el servidor, así que el navegador
      recibe HTML completo: el sitio se puede leer sin JavaScript y
      los buscadores lo indexan sin problema.

  - Dos idiomas sin bibliotecas externas.
      Cada página es un componente de app/_views que recibe el idioma
      ("es" o "en"). Las rutas en español están en app/(es) y las
      inglesas en app/en; cada carpeta tiene su propio layout raíz,
      así el <html> lleva el lang correcto. Los textos de la interfaz
      están en app/i18n/dictionaries.js, las rutas de cada página en
      los dos idiomas en app/i18n/config.js, y en los datos cada texto
      traducible es un objeto { es, en }. Cada página indica a los
      buscadores su versión en el otro idioma (hreflang).

  - Buscador en el servidor (app/data/searchIndex.js).
      El índice se construye con los mismos datos que usan las
      páginas, así cualquier elemento nuevo aparece en la búsqueda.
      Es un formulario GET normal: funciona sin JavaScript, ignora
      mayúsculas y tildes, y ordena primero las coincidencias en el
      título.

  - Datos separados del diseño (app/data/*.js).
      Las listas de música, videojuegos, series, aficiones, formación,
      experiencia, contacto y referencias son arrays de objetos.
      Añadir un elemento es copiar un objeto, sin tocar las páginas.

  - next/image para las imágenes.
      Genera automáticamente versiones más ligeras (WebP) y del tamaño
      justo para cada pantalla, reserva el espacio de la imagen para
      que la página no salte al cargar y retrasa la carga de las que
      no se ven todavía.

  - Vídeo y audio con las etiquetas nativas de HTML5.
      Los tráileres usan <video> y los fragmentos de los álbumes
      <audio>, con los controles del navegador, que ya son accesibles
      por teclado. Todos los archivos multimedia son locales (carpeta
      public/media). No se descarga nada hasta que se pulsa
      reproducir, y hay un enlace de descarga como alternativa.

  - Ventana del tráiler con <dialog> nativo
      (app/components/TrailerDialog.js). "Ver tráiler" es un enlace
      normal al vídeo, así funciona sin JavaScript, sin CSS o en modo
      lectura. Con JavaScript abre el vídeo en un <dialog>:
      showModal() bloquea el resto de la página, lleva el foco a la
      ventana, se cierra con Escape, con el botón o pulsando fuera, y
      devuelve el foco a la portada.

  - CSS puro con CSS Modules.
      Cada página tiene su hoja de estilos (*.module.css) y Next.js
      renombra las clases para que no choquen entre páginas. Los
      colores son variables CSS en app/globals.css, una tabla para el
      modo claro y otra para el oscuro.

  - Sin bibliotecas externas de interfaz ni recursos de terceros.
      El JavaScript propio es el botón de tema
      (app/components/ThemeToggle.js), la ventana de los tráileres, el
      menú que marca la sección actual (NavMenu.js), el botón del
      menú de móvil (MenuToggle.js) y el enlace al otro idioma
      (LanguageSwitch.js). La preferencia de tema se guarda
      en localStorage y, si no hay ninguna, se respeta la del sistema.

  - ESLint con la configuración de Next.js (core-web-vitals) para
      detectar errores y malas prácticas.


3. ESTÁNDARES Y ACCESIBILIDAD
------------------------------------------------------------------

  - HTML semántico (header, nav, main, section, article, figure,
    address, time) y encabezados en orden.
  - Idioma declarado en cada página (lang="es" o lang="en") y
    metadatos (título, descripción, URL canónica y versión en el otro
    idioma).
  - Enlace "Saltar al contenido principal", navegación por teclado y
    foco visible. La lista de videojuegos recibe el foco y se puede
    desplazar con las flechas.
  - Sección actual marcada en el menú (aria-current) y enlaces
    visitados en otro color.
  - Texto alternativo descriptivo en todas las imágenes ("Portada
    de ...", "Fotografía de ...").
  - El contenido y los tráileres se pueden usar sin CSS y sin
    JavaScript.
  - Diseño adaptable a móviles.
  - Modo claro y oscuro con contraste suficiente y color-scheme
    correcto.
  - Validado con el validador HTML del W3C (sin errores ni avisos) y
    el validador CSS del W3C (sin errores; solo los avisos de que las
    variables CSS no se comprueban).


4. ESTRUCTURA DEL PROYECTO
------------------------------------------------------------------

  app/                     Código del sitio (App Router de Next.js).
    (es)/                  Rutas en español. layout.js es la
                           plantilla raíz en español y cada carpeta
                           (formacion, musica, videojuegos, series,
                           hobbies, contacto, buscar, mapa, ayuda)
                           tiene un page.js que muestra su vista.
    en/                    Lo mismo en inglés (education, music,
                           videogames, series, hobbies, contact,
                           search, sitemap, help).
    _views/                Una vista por página, con sus textos en
                           los dos idiomas y su hoja de estilos.
    components/            Componentes reutilizables: plantilla común
                           (SiteShell), menú, enlace de idioma, migas
                           de pan, botón de tema, ventana del tráiler.
    i18n/                  Rutas, idiomas, fecha de actualización y
                           textos comunes.
    data/                  Contenido de las listas e índice del
                           buscador.
    globals.css            Estilos y colores globales.
    icon.svg               Icono de la pestaña.
    sitemap.js, robots.js  Generan /sitemap.xml y /robots.txt.

  public/                  Archivos que se sirven tal cual.
    sergio.jpg             Foto personal.
    covers/                Portadas e imágenes de cada sección.
    covers/placeholder.svg Imagen por defecto si falta una portada.
    media/videos/          Tráileres en MP4, en videojuegos/ y series/.
    media/audios/          Fragmentos de unos 30 s de cada álbum (MP3).

  package.json             Dependencias y scripts.
  next.config.mjs          Configuración de Next.js.
  eslint.config.mjs        Configuración de ESLint.
  leeme.txt                Este archivo.

No se entregan las carpetas node_modules/ ni .next/: se generan con
"npm install" y "npm run build".


5. DESPLIEGUE
------------------------------------------------------------------

Requisitos: Node.js 20.9 o superior y npm.

5.1. Desarrollo en local

    npm install
    npm run dev

  y abrir http://localhost:3000 (en inglés: http://localhost:3000/en)

5.2. Comprobaciones

    npm run lint
    npm run build

5.3. Producción

    npm install
    npm run build
    npm start

  sirve el sitio en http://localhost:3000. También se puede publicar
  en Vercel importando el repositorio: detecta Next.js y ejecuta la
  compilación automáticamente. El buscador se genera en el servidor
  en cada búsqueda; el resto de páginas son estáticas.


6. AÑADIR O CAMBIAR CONTENIDO
------------------------------------------------------------------

  Los textos que cambian con el idioma se escriben como
  { es: "texto en español", en: "English text" }. Si un texto es igual
  en los dos idiomas (un nombre propio, por ejemplo) basta con una
  cadena.

  Videojuegos (app/data/videogames.js), música (app/data/music.js),
  series (app/data/series.js) y aficiones (app/data/hobbies.js):

    1. Copiar un objeto del array y cambiar sus datos.
    2. Guardar la imagen en la carpeta correspondiente de
       public/covers y poner su ruta en "cover".
    3. Si no se indica "cover", se muestra public/covers/placeholder.svg.

  Formación, experiencia, formas de contacto y personas que me avalan:
  app/data/profile.js. Las fechas van en formato ISO (2026 o
  2026-03-02).

  Al actualizar el contenido, cambiar LAST_UPDATED en
  app/i18n/config.js: es la fecha que sale en el pie y en el sitemap.

  Tráiler de un videojuego o una serie: guardar el MP4 (H.264 + AAC)
  en public/media/videos/videojuegos o public/media/videos/series y
  poner su ruta en el campo "trailer". Para que empiece a reproducirse
  antes de descargarse entero, conviene mover el índice al principio
  del archivo:

    ffmpeg -i original.mp4 -c copy -movflags +faststart public/media/videos/series/serie.mp4

  Fragmento de un álbum: guardar el fragmento en MP3 en
  public/media/audios y, en app/data/music.js, añadir al grupo
  snippet: { src: "/media/audios/<id>.mp3", track: "<canción>" }.
